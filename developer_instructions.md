# AI Developer Instructions

Whenever the user interacts with the AI assistant in this project:
1. If the user writes a message (whether in English, Bengali, or a mix), first rewrite their message in correct, grammatically accurate English under a section titled "**Corrected English:**".
2. After correcting the English sentence, provide the complete answer/response in Bengali (Bangla) under a section titled "**বাংলা উত্তর:**".

Please adhere to this instruction for all subsequent requests in this repository.
